## Backend (Maven) 

Để chạy Spring Boot backend:

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

Backend sẽ chạy tại `http://localhost:8080`

**Lưu ý:** Cần khởi động MySQL (XAMPP) trước khi chạy backend.

## Frontend (Angular)

Để chạy Angular frontend:

```bash
cd frontend  
npm install
ng serve
# hoặc npm start
```

Frontend sẽ chạy tại `http://localhost:4200`
